# 撼動整合行銷官方形象網站

完整的單頁式活動整合行銷網站。

## 部署

目前儲存庫：<https://github.com/hantongltd/hantongltd-username.github.io>

若要透過 GitHub Pages 發布：

1. 開啟儲存庫的 **Settings**。
2. 點選左側 **Pages**。
3. 在 **Build and deployment** 的 **Source** 選擇 **Deploy from a branch**。
4. 選擇 `main` 分支與 `/ (root)`。
5. 按 **Save**。
